# Tasks for Today Management System

A simple task management web application built using CodeIgniter 4, PHP, and MySQL.

The system allows users to view today's tasks, browse all tasks, view a demo user profile, and learn about the developer.

## Technologies Used

- CodeIgniter 4
- PHP
- MySQL
- HTML
- CSS
- MVC Architecture

## Features

### Today's Tasks
Displays only tasks scheduled for the current date.

### All Tasks
Displays all tasks stored in the database, ordered by task date.

### Profile
Displays the demo user's information.

### About
Provides information about the project and its developer.

## Requirements

- PHP
- Composer
- MySQL
- XAMPP or another local PHP/MySQL environment
